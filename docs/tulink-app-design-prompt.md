Design a mobile app called "Tu-Link" — a real-time convoy coordination app for groups traveling together. Tu-Link lets drivers create and join journey sessions, track each other live on a map, receive lag alerts when someone falls behind, and see arrival statuses. Think motorsports culture: bold, fast, and premium.
THEME & VISUAL IDENTITY:
Primary color: Deep carbon black (#0D0D0D) with electric red (#E8002D) accents — inspired by Ferrari and F1 race liveries. Secondary: Brushed steel grey (#2A2A2A). Text: White (#FFFFFF) and light silver (#C8C8C8). Highlight/CTA buttons: Electric red with white text. Use Rajdhani or Bebas Neue for headings (bold, condensed, racing-inspired) and Inter for body text. Design language: Dark mode only. Sharp edges on cards, subtle red glows on active elements, speed-line motion graphics as decorative accents. The overall feel is a racing dashboard meets premium mobile app — think F1 telemetry HUD crossed with a sleek mobile UI.
SCREENS TO GENERATE (generate all of the following):

Splash/Onboarding Screen — Full-screen dark background, Tu-Link logo centered (stylized "TL" monogram with a speed-line motif), tagline "Stay in Formation." below, and a glowing red "Get Started" CTA button at the bottom.
Sign Up Screen — Email field, password field, confirm password field. "Create Account" primary CTA in red. "Already have an account? Sign In" link below. Social sign-in row (Google, Apple) with divider. Clean dark card layout.
Sign In Screen — Email and password fields. "Sign In" CTA. "Forgot Password?" link. "Don't have an account? Sign Up" link. Same dark card aesthetic.
Email Verification Screen — Illustration or icon of an envelope with a speed/signal motif. "Verify Your Email" heading. Instruction text. 6-digit OTP input boxes in a row (styled with red border on active). "Resend Code" timer link.
Forgot Password Screen — Email input field. "Send Reset Link" CTA. Back to Sign In link.
Home / Dashboard Screen — Bottom navigation bar with icons: Home, Journeys, Map, Notifications, Profile. Top greeting "Welcome back, [Name]" with small avatar. Two large cards: "Start a Journey" (red gradient CTA card) and "Join a Journey" (outlined card). Below: "Recent Journeys" list with journey name, date, member count, and a status badge (Completed/Active).
Create Journey Screen — Form fields: Journey Name, Destination (with map pin icon), Start Time (datetime picker). "Invite Members" section showing a search field and avatar row of invited contacts. "Set Lag Alert Threshold" slider (e.g. 2 min, 5 min, 10 min). "Launch Journey" red CTA button at bottom.
Active Journey / Live Map Screen — Full-screen dark map (Google Maps dark style) as background. Bottom sheet card showing: Journey name, member count, ETA to destination. Member avatars overlaid on the map at their live positions with speed indicators. Top bar showing journey status "IN PROGRESS" with a pulsing red dot. A "End Journey" button in red.
Member Lag Alert Screen — Full-screen alert overlay on the map. Warning icon in red. "[Driver Name] is falling behind — 3.2 km gap detected." Two action buttons: "Notify Group" and "Dismiss." Styled like a racing warning flag notification.
Journey Detail / Summary Screen — Post-journey recap screen. Route displayed on mini map. Stats row: Total Distance, Duration, Members, Avg Speed. Member list showing who arrived and when. "Share Summary" and "Start Again" action buttons.
Profile Screen — User avatar (large, circular with red ring border). Display name and email below. Stats row: Total Journeys, Total Distance, Journeys Led. Edit Profile button. Settings list items: Notifications, Privacy, Linked Accounts, Help & Support, Sign Out (in red).
Notifications Screen — List of notification cards. Types: Journey invite, lag alert, member arrived, new follower. Each card has an icon, bold title, subtitle text, and timestamp. Unread cards have a red left-border accent.

DESIGN PRINCIPLES:

Dark mode throughout, no light screens
Consistent 16px border radius on cards
Red (#E8002D) used only for CTAs, active states, alerts, and accents — never overused
Bottom navigation persistent across all main screens
Racing/motorsports decorative elements: subtle speed lines, checkered flag micro-patterns on dividers, tachometer-style progress indicators where relevant
High contrast typography — white on dark always
Mobile screen size: 390×844px (iPhone 14 Pro standard)
